# Jesionowski Family

The public family field guide, including the Jesionowski surname, our modern crest, and our family mythos of connecting heaven and earth.

Edit the site in `index.html`, the styling in `styles.css`, or the artwork in `assets/`. GitHub Pages publishes the root of `main` after updates. No dependencies or build steps are required. To preview, serve the repository over localhost with a static server such as `python3 -m http.server`.

GitHub Pages enforces HTTPS. The content security policy in each page permits local scripts, styles, and images. It blocks background network connections and form submissions, so keep the Research Desk and worksheet local to the browser.

Family history contributions should cite the underlying record. Ask permission before publishing a living person’s story or photo. Keep private family records outside this public repository.

## Roots atlas

The atlas lives in `roots/`. Its citations appear alongside each claim. The family-tree worksheet keeps inputs in the current page and exports a plain-text file directly in the browser.

The timeline and historical surname index live in `tree/`. Each branch cites the sources that name its relationships. Individual sightings stay separate until a record connects them. The modern family chart cites family testimony and published records.

The Source Book lives in `sources/`. Each record page identifies the version consulted, separates recorded wording from interpretation, and links back to the archive or published source.

The Research Desk lives in `research/`. It keeps the active draft in the page, with an editable JSON download to reopen later and a plain-text export for reading. Draft contents stay on the device.

Jesionowski Today lives in `today/`. Its searchable directory describes public work and cites official sources and verified work profiles. Visitors can share their own background and links in an optional public post and request inclusion in the directory. Keep the directory separate from the historical family branches.
